Privacy Policy

At AranBuy, user privacy is respected and protected. This Privacy Policy outlines how information is handled within this demonstration platform. Since AranBuy is an academic project, no real personal data is collected, stored, or shared for commercial purposes.

Any information entered on this website, such as login credentials or email addresses, is used only for front-end demonstration purposes. The data remains stored locally in the user’s browser and is never transmitted to external servers or third-party services.

Information Usage

The website may simulate user interaction such as login, cart storage, or wishlist features. These interactions are implemented using browser storage technologies like LocalStorage to demonstrate how user sessions can be managed on the client side.

No cookies, trackers, or analytics tools are actively used to monitor user behavior. AranBuy does not collect IP addresses, location data, or browsing habits.

This platform does not store, sell, or misuse any personal information.

Security Awareness

While this project does not implement real authentication or encryption mechanisms, it highlights the importance of data security in real-world applications. Developers are encouraged to integrate secure back-end systems when converting this project into a production-ready website.

Users are advised not to enter real or sensitive personal information while interacting with this demonstration platform.
