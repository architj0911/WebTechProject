Frequently Asked Questions

Is AranBuy a real shopping website?

No. AranBuy is a demonstration project created for academic learning. It does not sell real products or accept payments.

Do I need to create an account?

Account creation is optional and simulated. It exists to demonstrate how authentication systems work on the front end.

Is my data safe?

The website does not store data on servers. Any information is stored temporarily in your browser for demonstration purposes.

Can this project be extended?

Yes. This project can be enhanced by adding back-end technologies such as PHP, MySQL, or APIs to convert it into a full-stack application.
